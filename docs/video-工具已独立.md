# 讲解视频工具已独立为新项目

V0.1 讲解视频（约 18 分钟，1080p，中文配音 + 字幕）的全自动生成工具已从本仓库**完全独立**，不再存放于 `docs/video/`。

- 新仓库：<https://github.com/litaofox/mydatama-video>
- 首个版本标签：`v0.1.0`（兼容本项目 **v0.1.0** 的公开 HTTP 契约）
- 一键出片：`docker compose --profile video run --rm builder`（详见新仓库 README）

## 项目边界

新项目是本平台的**黑盒客户端**：仅通过 `http://BASE_URL` 访问登录页与 `/api/**` 公开接口驱动演示并截图，不包含、不引用、不共享本项目的源码、数据库或基础设施；独立仓库、独立版本号、独立容器镜像与发布节奏。平台后续版本若改动公开接口或前端路由，兼容性以新仓库 README 的「兼容矩阵」为准。

原 `docs/video/` 下的分镜稿、手工字幕、操作清单、slides.html 已在新仓库 `assets/` 中独立维护（含后续修正，例如合规反面演示以「密级倒挂稳定触发 R1」为准）。
