## 2. 录制前准备

### 2.1 软件（全部免费）

| 用途 | 软件 | 说明 |
|---|---|---|
| 录屏 | **OBS Studio** 30+ | 1920×1080，30fps，采集"浏览器窗口 + 系统声音 + 麦克风" |
| 配音（二选一） | 本人麦克风 / TTS | 推荐先录音再对画面；不愿真人出声可用剪映"文本朗读"或 edge-tts |
| 剪辑 + 字幕 | **剪映专业版** | 导入 SRT 自动上字幕；或 DaVinci Resolve / Premiere |
| 代码展示 | IntelliJ IDEA（后端）、VS Code（前端/Python） | 字体调大到 18pt+，浅色或深色主题统一 |
| 章节卡 | Chrome/Edge 打开 [slides.html](./slides.html) | F11 全屏，← → 翻页 |

TTS 批量合成（可选，需联网，免费）：

```bash
pip install edge-tts
# 把旁白稿每段文字存为 txt，逐段合成；或直接在剪映里用"文本朗读"
edge-tts --voice zh-CN-YunxiNeural --rate=-5% --text "旁白内容" --write-media seg1.mp3
```

### 2.2 录制参数（保证"画质清晰、声音清楚"）

- 分辨率 **1920×1080**、30fps、码率 8–12 Mbps（OBS：CBR 10000 Kbps）；
- 麦克风：安静房间，手机耳麦即可；OBS 麦克风音量 -10dB 左右，峰值不爆红；
- 录前关闭：微信/邮件弹窗、Windows 通知、浏览器无关标签页；
- 浏览器缩放 100%，系统缩放建议 100%（避免录出来字小）；
- 演示前先 `docker compose down -v && docker compose up -d --build` 造空态，保证第 1 步大屏是全 0。

### 2.3 录制顺序建议（不要从头到尾一遍过）

1. **先录旁白**：照逐字稿分段录音（每镜一段，念错重念该段即可）；
2. **再录画面**：戴耳机听自己的旁白，按旁白节奏操作录屏；
3. **代码章节**：滚轮和光标移动放慢，每个关键类停留 3 秒以上；
4. **剪辑**：按分镜表拼接，导入 SRT 校对时间轴，片头片尾加章节卡；
5. **导出** MP4（H.264 + AAC），文件名建议 `mydatama-v0.1-讲解视频-1080p.mp4`。
